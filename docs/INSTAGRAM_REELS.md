## How to post (per reel)

1. Download the video to your phone (AirDrop from `~/madeirabook-media/out-video/`).
2. Open Instagram → `+` → Reel → select the video.
3. Pick a cover frame, add trending audio if the original sound is weak.
4. Copy the **Caption** from the table above into the caption field.
5. Paste the **Hashtags** from the same row at the end of the caption.
6. Post. Optional: pin the first comment or add location "Madeira, Portugal".

Suggested order: 3 (dolphins — strongest hook) → 1 (surfer) → 4 (cliffs) → 2 (forest) → 5 (estate) → 6 (arrival). One reel per day.
